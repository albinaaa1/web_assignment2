## Description
This project demonstrates modern layout techniques using CSS Flexbox and CSS Grid without relying on float properties or third-party CSS frameworks.

## Structure
- `index.html`: Contains Task 0 (Flexbox Navigation Bar) and Task 1 (Flexbox Card Row).
- `grid.html`: Contains Task 2 (Page Layout with Grid Areas) and Task 3 (Image Gallery with captions on hover ).
- `portfolio.html`: Contains Task 4 (Portfolio Page combining Flexbox & CSS Grid).
- `style.css`: Contains all custom styles for the assignment.
